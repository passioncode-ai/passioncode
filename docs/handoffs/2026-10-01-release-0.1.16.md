# Release 0.1.16: npm 12 compatibility

## Objective and failure receipt

Publish the launcher runtime fixes and canonical-backlog instructions after the
0.1.15 release stopped before npm publication. The immutable `v0.1.15` tag points
at `a85bbaa3afd87f4cf6ea8cb3b3ba7e91e5f7a1b0`; its GitHub release exists, but npm
publication was skipped. [Workflow 36891117466](https://github.com/passioncode-ai/passioncode/actions/runs/36891117466)
passed source validation and tagged-member validation. The publish job's packed
smoke failed with `TypeError: object is not iterable` on npm 12.2.0 / Node 24.21.0.

npm 11 returns a JSON array from `npm pack --json`. npm 12 returns an object keyed
by the package name. This was reproduced locally using the actual npm 12.2.0 CLI
from its published package: the original smoke failed at the same destructuring.
The actual npm 12.2.0 `npm view` command also returned a singleton array for
version, maintainer and publisher metadata. The previous update probe rejected
that answer. The new regression fails against the original parser, and the fixed
probe reads the actual latest registry response with the trusted OIDC publisher.
No release tag was moved, no publication gate was weakened and no user-home install
was used to test the fix.

## Implementation

`scripts/pack-result.mjs` accepts either format, requires exactly one usable local
tarball, and preserves its file list and integrity. `scripts/smoke-pack.mjs` calls
it before extraction. `test/pack-result.test.js` covers npm 11, npm 12 and refusal
of empty, multiple, path-escaping or malformed records. Package and self-plugin
versions are 0.1.16; this skill has no separate metadata.version field. Family
members stay at Fabric Agent Adapter v0.5.5 and Project Observatory v0.10.0
(Observatory Log 0.13.0).

The update probe normalizes only a one-element array before its existing version
and identity checks. The regression in `test/self-update.test.js` proves the same
pinned trust decision as the object format; empty, nested, multiple and malformed
arrays, missing publishers and malformed maintainers cannot authorize an update.
