# Launcher CLI voice

Voice pack: operator-brief
Locales: en (primary)
Derived-from: inferred
Status: draft
Humanization: on
Humanization pass: own
Last calibrated: 2026-10-01

Scope: launcher command diagnostics and session-start notifications. Inferred from
the existing English CLI; this is not an approved organisation-wide brand pack.
The bug audit extends the status-only vocabulary without changing product positioning.

| Axis | IS | IS NOT |
|---|---|---|
| Confidence | Explicit about the source and time of an observation | Claiming a live check from saved data |
| Register | Plain technical English | Promotional |
| Distance | Direct labels | Familiar banter |
| Humor | None in diagnostics | Jokes about installation state |
| Density | Short labels with necessary context | Explanations repeated on every row |

The operator is the actor; ambiguous state is the problem. The launcher reports
what it knows. Its promise is limited to the observation it can substantiate.

Invariant: installed, package and cached registry versions are distinct facts.
