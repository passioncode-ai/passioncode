# CLI channels

### docs and help

- Register: terse, concrete labels; no deviation from the draft voice.
- Format: status summary/member rows, update step list, or a concise error with a recovery action.
- Limits: keep provenance beside the value; no additional command or prompt.
- Forbidden: physics: ANSI-dependent meaning | brand: unsourced freshness claims.
- CTA: none in status; failed mutations explain how to fix the cause and retry.
- Proof: saved fields and CLI regression tests.
- Locales: en.

### notifications

- Register: the same concrete diagnostic voice.
- Format: one line prefixed with `[passioncode]`.
- Limits: report a started update only after process creation succeeds.
- Forbidden: physics: blocking the session on a background command | brand: implying installation success from a spawn.
- CTA: a pinned manual command, or repair PATH and retry next session.
- Proof: `decide()` and session-hook regression tests.
- Locales: en.
